# contact

Landing pages de redirección de El Universal (Audiencias). Cada página muestra una cuenta regresiva de 3 segundos y redirige al destino (WhatsApp u otro enlace), con medición mediante GoatCounter y Pixel de Meta.

Publicadas con GitHub Pages en `https://audiencias-eluniversal.github.io/contact/<carpeta>/<archivo>.html`.

## Carpetas

- `luchy-coach` – Neuro Reset
- `magic-and-moments` – despedida de soltera, pedida de mano
- `multydrink` – Multydrink
- `newport` – Newport
- `promotora-dirc` – La Ramada Caribe
- `PyM` – hogar, salud, vehículos
- `supergiros` – SOAT

## Crear o actualizar una página

1. Copiar una página existente (base: `luchy-coach/neuro-reset.html`) y ajustar metadata y `urlDestino`.
2. Verificar que el HTML tenga el Pixel de Meta; si no, agregarlo desde `pixel_meta.txt` dentro de `<head>`.
3. Mantener el script de GoatCounter.
